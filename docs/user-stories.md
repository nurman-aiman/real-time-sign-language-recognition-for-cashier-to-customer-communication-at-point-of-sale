# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a cashier, I want to turn on sign language recognition with one click on the POS, so that I can serve a deaf customer without leaving the till.
2. As a cashier, I want the customer's signs shown as text on my POS screen, so that I understand what they want to buy or ask.
3. As a deaf customer, I want to sign in BIM to the camera, so that I can ask for what I need without writing notes or waiting for an interpreter.
4. As a cashier, I want the camera to be on only while I am using this option, so that customers' privacy is protected.
5. As a cashier, I want to clear the text and try again, so that a mistake does not stay on the screen
